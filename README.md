
# CNC Club Feedback Page

A simple and responsive feedback webpage for the **CNC Club, IISER Bhopal**, built using HTML.

## Features
- Clean, modern dark-themed interface
- Responsive design for desktop and mobile
- Optional name and email fields
- Feedback category selection
- Interactive five-star rating system
- Feedback text box and submit button

## Technologies Used
- HTML

## How to Run
1. Clone or download this repository.
2. Open `feedback.html` in any web browser.

## Note
This is currently a frontend-only project.
